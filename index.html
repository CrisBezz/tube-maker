Inset surface web

Each face is inset in its own plane. The centre opening is removed and the remaining border is welded into a single exported mesh. Width is reduced locally if a face would collapse.

Solid surface web

The inset web is duplicated and offset along averaged vertex normals. All open boundaries, including hole boundaries, are bridged to create one closed mesh while keeping the openings clear.

Symmetry
