MESH LINE REPLACER — STABLE SAFARI / IPAD VERSION

Stable replacement modes:
1. Faceted cylinders / tubes, including overlap, mitre and welded-hub junction modes.
2. Inset surface web geometry.

The experimental Triangulated Tubes mode has been removed pending further development.

INSET SURFACE WEB MODE
- Returns to the original mesh faces instead of orienting independent ribbons.
- Insets every usable face inside its own plane.
- Removes the centre opening.
- Keeps the surrounding border ring.
- Merges and welds all face rings into one single-face-thick output mesh.
- Reduces web width locally where necessary to prevent collapsed insets.

INSTALL / UPDATE ON GITHUB PAGES
Replace index.html, sw.js, manifest.webmanifest and README.txt in the existing repository and commit. GitHub Pages will update automatically.
