MESH LINE REPLACER — SAFARI / IPAD VERSION

This static web app converts extracted model edges into either:
1. Faceted cylinders / tubes, with overlap, mitre and welded-hub junction modes.
2. Centred quad faces / ribbon strips.

RIBBON MODE
- One centred quad is created for each extracted edge.
- Coincident vertices are welded.
- Junction gaps are filled with triangulated fans.
- The result is exported as one mesh object, one face thick.
- Ribbon reference normal may be Auto, X, Y or Z.
- Symmetry, reconstructed quads and original OBJ quads remain available.

INSTALL / UPDATE ON GITHUB PAGES
Replace index.html, sw.js, manifest.webmanifest and README.txt in the existing repository and commit. GitHub Pages will update automatically.
